# 标记磁盘

每个大宗磁盘的过滤决定它存什么。标记器让你在一个界面里编辑所有已挂载磁盘的过滤。

## 63 格网格

每个格子显示一个磁盘的过滤，尚未标记的磁盘显示为空格。

* <ItemImage id="minecraft:diamond" /> **手持物品左键**：把该格对应磁盘的过滤设为这个物品。
* **空手左键**：清除该磁盘的过滤。
* 每格只放一个物品，剩余的堆留在光标上。
* 若其他磁盘已有完全相同的过滤，会先把它盘内的物品搬进新盘、再清除其过滤——标记连
  同物品一起搬家到新格；仅因压缩链覆盖该物品（过滤为同链其他变体）的磁盘不动。
* 无过滤但装满的滞留盘会在格子里显示盘内物品。**空手左键**把内容抽回网络（消耗能量，
  与 IO 接口一致）；自动标记按钮则会自动修复滞留盘。

## 翻页

左侧工具栏有 ◀ 和 ▶ 按钮，磁盘超过 63 个时用于翻页。不可用的按钮会置灰，
按钮本身不会移动或消失。

## 自动标记按钮

左侧工具栏的按数量排序按钮（位于 ◀ 和 ▶ 下方）根据网络实际存储的物品，一次标记所有空白磁盘：

1. 网络里的物品按存量从多到少排序。
2. 每个物品被写入第一个过滤为空的磁盘——已被现有过滤覆盖的物品（包括压缩卡磁盘覆盖的
   同压缩链变体）跳过。
3. 没有空白磁盘时停止标记。

标记前会先自动修复滞留盘（无过滤但装满）：把盘内物品写回为过滤。随后合并过滤完全相同
的磁盘：内容并入其中一个能全部装下的盘，其余磁盘取消标记，腾出来给新的标记使用。

标记完成后，标记器会把网络内容转移进对应的大宗盘：

* 每个已过滤的磁盘把对应物品从网络其余存储拉进盘内。
* 只从非大宗存储（普通元件、储物总线等）抽取——大宗盘之间不互相抽取。
* 转移消耗网格能量（与 IO 接口一致），能量不足的物品留在原处。
* 装了压缩卡的磁盘会把整条压缩链一起拉入（例如过滤为铁锭时，铁粒、铁锭、铁块都会进盘）。
* 已在盘内的物品原地不动；超出磁盘剩余容量的物品留在网络中。

网络中没有挂载任何大宗磁盘时，按钮置灰。
