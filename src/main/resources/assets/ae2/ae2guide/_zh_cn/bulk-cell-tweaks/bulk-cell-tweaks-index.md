# Bulk Cell Tweaks

Bulk Cell Tweaks 加入了 **大宗存储元件标记器**，一个用于管理 ME 网络中所有已挂载的
MEGA Cells 大宗磁盘过滤配置的方块，一切都在同一个 GUI 里完成。

无需逐个打开驱动器、ME 箱子或元件坞——标记器在一个界面里列出所有已挂载的大宗磁盘。
你可以手动设置或清除每个磁盘的过滤、把过滤逐个盖到空白磁盘上，以及装卸压缩卡。
