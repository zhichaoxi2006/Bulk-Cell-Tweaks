# Bulk Cell Tweaks

Bulk Cell Tweaks adds the **Bulk Cell Marker**, a ME network block for managing the filters of
MEGA Cells Bulk Cells mounted anywhere in your network, from a single GUI.

Instead of opening every drive, ME chest, or cell dock one by one, the marker shows every mounted
bulk cell in one screen. You can set or clear each cell's filter by hand, stamp a filter onto
empty cells one at a time, and install or remove compression cards.
